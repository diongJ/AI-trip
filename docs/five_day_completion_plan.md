## 3. 技术方案冻结

为避免五天内反复选型，冲刺开始后按以下方案执行；只有出现明确阻塞才启用备选方案。

### 3.1 RAG

- 输入：`data/raw/**/*.json` 中的 36 份官方资料。
- 切分：按自然段优先，长段按句号切分；建议每片段 300～500 个中文字符，重叠 50～80 字。
- Metadata：每个片段必须保存 `chunk_id`、`doc_id`、`title`、`source_name`、`source_url`、`category` 和原文。
- 向量检索：使用轻量多语言句向量模型生成 embedding，并以 FAISS 建立本地索引。
- 召回：默认 Top-5；对重复片段按 `doc_id + text` 去重。
- 回答上下文：只拼接 Top-3～5 个片段，保留文档编号和来源链接。
- 兜底：若部署环境无法稳定加载句向量模型，保留一个轻量词法检索后端；接口和返回模型不变。

### 3.2 KG 检索

- 先使用 `entity_resolution_v1.json` 和图谱实体别名解析问题中的候选实体。
- 查询结果包含实体名称、关系方向、关系类型、`document_id` 和 `evidence`。
- 查询范围默认一跳；只有明确的关系追问才使用两跳，并限制返回数量，避免路径爆炸。
- Neo4j 不可用时允许从 `knowledge_graph_v1.json` 读取同构的本地只读图，保证 Demo 有降级能力。

### 3.3 Agent

- 工具仅设置为 `search_kg`、`search_documents` 和 `hybrid_search`，避免工具数量失控。
- 路由采用“确定性规则优先、LLM 补充判断”的可解释方案。
- 回答模板固定包含：直接回答、证据说明、来源列表；证据不足时输出拒答提示。
- LLM 只能基于工具返回的上下文组织语言，不允许把模型自身记忆当作来源。
- 输出中保留结构化引用对象，页面层负责将其渲染为可点击来源。

### 3.4 应用与部署

- 应用框架：Streamlit。
- 页面：首页、智能问答、AI 深度讲解、图谱探索。
- 部署首选：可托管 Streamlit 应用的平台；使用平台 Secrets 配置 DeepSeek 和 Neo4j 凭据。
- 不把 `.env`、模型缓存、FAISS 临时文件或凭据提交到 Git。
- 若云端无法连接 Aura，应用自动切换到本地图数据；若 DeepSeek 不可用，页面给出清晰错误，不伪装成功。

## 6. Day 5：Agent MVP 与端到端问答（8 月 26 日）

### 当日目标

让用户问题能够经过路由、检索和受约束生成，返回带来源答案；建立明确拒答边界。

### 任务一：问题类型与路由规则

建立四类问题及默认策略：

| 问题类型 | 示例 | 默认工具 |
|---|---|---|
| 实体事实 | “文帝行玺由什么材料制成？” | KG，必要时 RAG 补充 |

| 描述与讲解 | “给我讲讲丝缕玉衣的特点和意义” | Hybrid |

- 规则路由覆盖明确关键词和实体命中。
- 模糊问题由 LLM 在三个工具中选择，但只能输出受控枚举。

### 任务二：工具封装与上下文组装

## 13. 风险、触发条件与应对

| 风险 | 触发条件 | 立即措施 | 不允许的处理 |
|---|---|---|---|
| 句向量模型在云端过大 | 冷启动持续过慢或内存溢出 | 换轻量模型或启用词法检索降级，保持接口不变 | 临时删除引用或跳过检索 |
| Neo4j Aura 不稳定 | 连续两次连接失败 | 切换本地 JSON 只读图，页面显示降级状态 | 返回伪造的云查询结果 |
| DeepSeek 超时/限流 | 重试后仍失败 | 显示可重试错误；保留已检索证据供用户查看 | 无提示地输出缓存旧答案 |
| Agent 出现幻觉 | 答案事实无法在证据中定位 | 收紧 Prompt、降低上下文、增加引用后校验或拒答 | 通过人工改写隐藏问题 |
| 评测时间不足 | Day 7 进入实验阶段时题集仍未冻结 | 先完成 30 题三组单次实验，稳定后再加重复运行 | 减少到只展示几个成功案例 |
| 在线部署失败 | Day 7 部署阶段结束后仍无可访问地址 | 立即启用第二托管方案，并准备本地录屏兜底 | 把本地地址称为公开 Demo |
| PPT/视频挤压开发 | Day 8 开始包装时仍有核心功能缺陷 | 冻结新功能，仅修 P0 缺陷；内容负责人同步准备材料 | 为追求页面细节跳过回归 |
| 图谱规模被质疑 | 评审对 78/87 的规模提出疑问 | 用来源审计、融合决策和零证据问题解释质量优先 | 虚报或使用未审计扩写数据 |
