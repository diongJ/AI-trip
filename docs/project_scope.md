# 项目范围说明

## 项目名称

基于大模型与智能体的南越王博物院深度知识图谱构建与智慧导览应用

## 研究目标

构建一个小而完整、可追溯、可演示的南越王博物院王墓展区知识系统。系统将可靠文本资料转换为结构化知识图谱，并结合文档检索和智能体，为游客提供有来源依据的问答与个性化讲解。

核心技术链路为：

```text
可靠资料 -> 文本清洗 -> LLM 实体/关系抽取 -> 实体融合 -> Neo4j
                                                    |
用户问题 -> Agent -> 图谱检索 + RAG 文档检索 ------+-> 有来源回答
```

## 研究范围

- 南越王博物院王墓展区。
- 南越文王墓、墓葬发现与发掘、墓室结构。
- 墓主人赵眜及与研究对象直接相关的人物。
- 30 至 50 件代表性出土文物。
- 与上述对象直接相关的西汉、南越国及多元文化交流知识。
- 文物、墓室、人物、历史事件和文化之间的可验证关系。

所有进入知识库的资料必须记录来源。所有由 LLM 抽取的实体和关系必须保留来源文档、原文证据与置信度。

## 非目标

- 不覆盖南越王博物院王宫展区或全馆全部藏品。
- 不扩展为广州或全国景点知识图谱。
- 不开发票务、开放时间、客流等实时服务。
- 不在第一阶段开发路线规划、定位导航或多模态识别。
- 不追求无人工审核的全自动实体消歧。

## 九天里程碑

| 日期 | 里程碑 | 验收结果 |
|---|---|---|
| Day 1 | 范围、Schema 和技术底座 | 文本可抽取为合规 JSON，并可写入 Neo4j |
| Day 2 | 可溯源语料库 | 30 至 50 份可靠资料及完整 Metadata |
| Day 3 | 批量抽取与图谱 V1 | 150 至 300 个实体，300 至 700 条关系 |
| Day 4 | KG 与 RAG 检索 | 两类检索均可返回相关内容和来源 |
| Day 5 | Agent MVP | 用户问题可经工具选择生成带来源回答 |
| Day 6 | 完整 Demo | 首页、问答、讲解、图谱探索可连续操作 |
| Day 7 | 部署与评测 | 在线 Demo 及三组真实对比实验 |
| Day 8 | 项目包装 | README、PPT、架构图、实验图表完整 |
| Day 9 | 最终交付 | 程序包、Git、PPT、Demo、视频通过检查 |
