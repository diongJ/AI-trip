# 南越王博物院游客导览资料采集任务书

更新日期：2026-08-27

## 1. 任务目标

本任务用于扩充南越专题问答系统的“游客参观与游览建议”资料，使系统除了回答历史、人物和文物知识外，还能可靠回答：

- 第一次去王墓展区应该怎么看？
- 只有 30 分钟或 1 小时，应该看哪些文物？
- 王墓展区最值得看的文物有哪些？
- 带孩子、学生、老人参观应该怎么安排？
- 开放时间、门票和墓室下层如何预约？
- 馆内有没有讲解、寄存、轮椅、婴儿车等服务？
- 王墓展区和王宫展区有什么区别，能否一起参观？

本轮重点不是继续收集泛泛的历史介绍，而是补齐“参观事实、空间位置、重点文物、游客需求和路线组织”资料。

## 2. 来源优先级

### A 级：可作为事实证据

优先收集以下官方来源：

1. 南越王博物院官方网站。
2. 南越王博物院官方微信公众号、微博及预约页面。
3. 广州市文化广电旅游局等政府文旅部门网站。
4. 博物院正式发布的导览图、楼层图、展览手册、PDF 和公告。
5. 广州地铁、公交等公共交通机构的官方页面。

建议首先检查：

- [南越王博物院参观指南](https://www.nywmuseum.org.cn/News/VisitIndex/Visit-0)
- [南越王博物院首页](https://www.nywmuseum.org.cn/Home/Index)
- [便民与无障碍服务](https://www.nywmuseum.org.cn/News/Details/fwjs)
- [南越文王墓下层参观公告](https://www.nywmuseum.org.cn/News/Details/tzgg?nid=12469)
- [王墓原址展示区暂停开放公告](https://www.nywmuseum.org.cn/News/Details/tzgg?nid=12496)

### B 级：可用于项目整理建议

以下内容可以用于设计游览路线，但不能冒充馆方规定：

- 根据官方楼层图、展览目录和文物位置整理的 30/60/120 分钟路线。
- 根据官方服务能力整理的亲子、学生、老人和无障碍参观建议。
- 根据馆方文物介绍整理的重点文物观看顺序和观察问题。
- 根据两个展区的地址、开放信息和展览主题整理的联动建议。

这类资料统一标记：

```json
{
  "source_type": "other",
  "source_name": "AI-trip 项目整理",
  "source_tier": "extended",
  "evidence_role": "curated_guidance"
}
```

### C 级：只用于发现游客问题

可以查看但不能作为事实引用：

- 小红书、微博普通用户内容。
- 大众点评、携程、地图评论。
- 个人旅游博客、短视频和自媒体攻略。
- 问答平台和论坛讨论。

这些内容只用于收集真实问法，例如“带娃累不累”“一小时够不够”“哪个最值得看”，不能用于证明票价、开放时间、馆方规定或历史事实。

## 3. 需要采集的资料

### 3.1 开放、门票与预约

- 常规开放时间和停止入场时间。
- 周一、法定节假日、寒暑假的开放规则。
- 王墓展区和王宫展区的票务区别。
- 成人票、半价票、免费票及适用人群。
- 实名预约、入馆证件和入场方式。
- 南越文王墓墓室下层预约方式、放票时间、限流和停留规则。
- 官方咨询和投诉电话。

时效要求：页面采集时必须记录发布日期、采集日期和适用期限。旧公告不得直接当作当前规则。

### 3.2 临时闭馆、维护与展览公告

- 临时闭馆和恢复开放通知。
- 墓室、遗址或展厅维护公告。
- 节假日延时开放公告。
- 临时展览的开始时间、结束时间和所在展区。
- 临时活动、夜游、讲座和研学活动。

所有临时资料必须填写 `effective_from` 和 `effective_until`；无法确定结束时间时需要标记“待官方更新”。

### 3.3 地址与交通

- 王墓展区和王宫展区的准确地址。
- 最近地铁站、出口和官方推荐步行入口。
- 公交站点。
- 两个展区之间的距离和官方推荐交通方式（如有）。
- 入口和出口是否不同。

只保存稳定的交通参考。实时拥堵、打车价格、停车位和实时导航不进入静态知识库。

### 3.4 馆内空间与文物位置

重点寻找：

- 官方导览图。
- 楼层图和平面图。
- 展厅名称、楼层和入口。
- 基本陈列、临时展览和墓原址区之间的位置关系。
- 重点文物所在展厅、展览单元、楼层或展柜。
- 电梯、楼梯、无障碍通道、卫生间、休息区和服务台位置。

建议最终整理为：

```text
展区 → 建筑 → 楼层 → 展厅/展览单元 → 文物/服务设施
```

### 3.5 代表性文物与推荐理由

优先寻找馆方明确标记为重点、代表性、精品或重要发现的文物。至少覆盖：

- 文帝行玺。
- 丝缕玉衣。
- 角形玉杯。
- 船纹铜提筒。
- 铜虎节。
- 墓主印章和重要玉器、青铜器组合。

每件文物需要记录：

- 官方名称和常见别名。
- 所在展区、楼层和展览单元。
- 官方推荐理由或重要性说明。
- 能回答的核心问题。
- 建议停留时间。
- 适合亲子、学生、历史爱好者或工艺爱好者中的哪些人群。
- 可继续观看的相关文物。

如果官方没有“最出名”“排名第一”的表述，不得自行创造排名。应整理为“代表性文物包括……”或“如果关注墓主身份，建议重点看……”。

### 3.6 讲解与导览服务

- 免费定时讲解的时间、地点、人数和参加方式。
- 收费人工讲解的购买方式、价格、语言和时长。
- 线上语音导览、二维码导览和讲解器。
- 多语种导览。
- 手语导赏和无障碍讲解。
- 研学、亲子和考古主题讲解活动。

收费、时间和名额可能变化，必须保留发布日期和官方链接。

### 3.7 馆内便民与无障碍服务

- 行李寄存和寄存柜。
- 轮椅、婴儿车、拐杖、助听器和老花镜。
- 无障碍坡道、电梯和卫生间。
- 母婴服务、儿童服务和休息区。
- 医药箱、咨询、投诉和失物招领。
- 饮水、充电、文创商店等官方确认的服务。

没有官方依据的服务不能写成确定事实。

### 3.8 参观规则与安全提示

- 拍照、闪光灯、三脚架和商业拍摄规定。
- 饮食、吸烟、宠物和大件行李规定。
- 儿童进入墓室的陪同要求。
- 墓室下层停留时间和安全要求。
- 文物保护、安检和禁止触摸规定。
- 突发情况和紧急联络方式。

### 3.9 不同游客的需求资料

收集可支持以下建议的官方事实：

- 第一次参观。
- 亲子家庭。
- 学生研学。
- 老年游客。
- 行动不便游客。
- 外语游客。
- 摄影或工艺爱好者。
- 只有 30 分钟、1 小时、2 小时或半天的游客。

路线建议可以由项目整理，但路线中的开放、楼层、文物位置和服务信息必须有官方来源。

## 4. 需要整理的路线方案

在事实资料采集完成后，再整理以下攻略：

1. 第一次参观王墓展区路线。
2. 30 分钟精华路线。
3. 1 小时重点路线。
4. 2 小时深度路线。
5. 半日王墓展区路线。
6. 王墓、王宫两展区联动路线。
7. 亲子观察路线。
8. 学生研学证据链路线。
9. 老人或少走路路线。
10. 无障碍参观路线。
11. 雨天室内优先路线。
12. 墓主身份、丧葬观念、工艺技术和海上交流四条主题路线。

每条路线应包含：

- 适合人群。
- 建议总时长。
- 起点和终点。
- 依次经过的展厅或文物。
- 每一站建议停留时间。
- 推荐理由和观察问题。
- 使用的官方事实来源。
- “项目整理建议”标识。

## 5. 文档字段模板

每份资料至少填写：

```json
{
  "doc_id": "DOC_XXX",
  "title": "资料标题",
  "source_name": "发布机构",
  "source_url": "https://...",
  "source_type": "official",
  "source_tier": "extended",
  "evidence_role": "factual",
  "category": "tourism",
  "published_at": "2026-08-27",
  "retrieved_at": "2026-08-27",
  "effective_from": "2026-08-27",
  "effective_until": null,
  "last_checked_at": "2026-08-27",
  "volatility": "stable",
  "zone": "王墓展区",
  "floor": null,
  "visitor_types": ["first_time"],
  "recommended_duration": null,
  "topic_tags": ["开放时间", "预约"],
  "review_status": "approved",

  "text": "完整正文或完整事实摘录",
```

当前 `CorpusDocument` 尚未包含其中全部参观扩展字段。队友可以先把这些字段记录在采集表中，后续再统一迁移到数据模型；不要擅自删除字段。

## 6. 更新频率

| 资料类型 | 建议复查频率 | 过期处理 |
|---|---:|---|
| 地址、展区定位 | 每季度 | 发现变化后更新版本 |
| 常规开放和票务 | 每月 | 新版本替换旧规则 |
| 讲解和馆内服务 | 每月 | 保留变更记录 |
| 节假日公告 | 每周或节前 | 到期后退出当前索引 |
| 临时闭馆和维护 | 每日或每周 | 恢复开放后立即失效 |
| 临时展览和活动 | 每周 | 结束后退出当前推荐 |
| 项目整理路线 | 官方信息变化后 | 重新审核涉及路线 |

## 7. 禁止事项

- 不得把游客评论写成官方事实。
- 不得根据印象虚构票价、开放时间、讲解时间或服务设施。
- 不得把“最出名”“最好看”“第一名”写成客观排名，除非馆方原文明确说明。
- 不得把临时公告永久保留为当前状态。
- 不得把项目整理路线写成“馆方官方推荐路线”。
- 不得采集实时客流、实时余票、停车空位、实时天气或导航价格作为静态资料。
- 不得复制没有来源 URL、发布日期或发布机构的内容进入事实库。
- 不得将 `curated_guidance` 写入知识图谱。

## 8. 交付物

队友最终需要提交：

1. `visitor_sources.xlsx` 或等价 CSV：资料清单、URL、来源等级、发布日期、采集日期、适用期限、审核状态。
2. 官方原始资料：网页正文、PDF、图片或手册原件。
3. 结构化事实表：展区、楼层、展厅、文物和服务设施位置。
4. 代表性文物表：文物位置、推荐理由、适合人群和关联文物。
5. 参观 FAQ：至少 50 个真实游客问题及标准意图。
6. 项目整理路线：至少 8 条，必须列出使用的官方来源。
7. 问题清单：无法确认、来源冲突或需要馆方核实的内容。

## 9. 验收标准

- 官方事实均有可访问的原始链接和发布机构。
- 时效资料均有发布日期、采集日期和适用期限。
- 展区、楼层、文物和设施位置能够形成清晰层级。
- 至少覆盖开放票务、预约、交通、讲解、便民服务、无障碍、参观规则、重点文物和路线九类问题。
- 至少提供 50 个游客常见问法，包含口语、简称和模糊表达。
- 项目整理建议与官方事实明确分开。
- 对“最出名、必看、镇馆之宝”等主观问法，不虚构官方排名。
- 所有待进入 RAG 的资料具有审核状态和正文哈希。

## 10. 推荐优先顺序

第一批先找：

1. 官方参观指南、参观须知、票务和预约页面。
2. 最新开放、闭馆和墓室维护公告。
3. 官方导览图、楼层图和展厅分布。
4. 基本陈列目录及重点文物所在位置。
5. 讲解、寄存、无障碍和亲子服务资料。

第二批再做：

1. 代表性文物推荐表。
2. 不同时长的游览路线。
3. 亲子、研学、老人和无障碍路线。
4. 游客常见问法和同义表达词典。

只有第一批事实资料审核完成后，才开始编写第二批项目整理建议。
